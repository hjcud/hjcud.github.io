# 이미지 출처와 소프트웨어 라이선스

## 프로젝트 화면

- **Hinasaki Shaders**의 눈물 셰이더 미리보기는 @mbM0001_가 2023년 4월 10일 게시한 시연 영상의 첫 프레임입니다. 셰이더는 hjcud가 개발했습니다. 코드의 Apache-2.0 라이선스는 원본 영상과 아바타에 적용되지 않습니다. [원본 영상](https://x.com/mbM0001_/status/1645361384719540226) / [프로젝트의 미디어 출처](https://github.com/hjcud/hinasaki-shaders/blob/main/docs/media/README.md)
- **VR 화재 시뮬레이터**의 소화기 장면은 손현준의 2023년 가상현실 수업 프로젝트 보고서에서 가져왔습니다.
- **ProPro**의 발음기호 화면은 H4 팀 캡스톤 최종보고서 18쪽의 앱 화면을 모아 구성했습니다.
- **Shinjuku Live Street**의 월드 화면과 제목 로고는 Artistoid가 그래픽과 모델링을, hjcud가 시스템을 담당한 프로젝트에서 가져왔습니다. 로고는 대표 이미지의 글자를 재배치했습니다. 웹 지도는 전시 프로젝트의 차선 좌표와 정지선을 사용합니다. [프로젝트와 제작진](https://github.com/hjcud/Shinjuku-Live-Street/blob/main/README.ko.md) / [프로젝트 이용 조건](https://github.com/hjcud/Shinjuku-Live-Street/blob/main/COPYRIGHT.md)
- **Shimanami Ekranoplan**의 비행 화면과 전시 사진은 mabetto와 hjcud의 프로젝트 기록입니다. mabetto가 기체, 환경 모델링과 조종석 구성을 담당했습니다. 제목 로고는 월드 대표 이미지의 글자를 재배치했습니다. 원본 코드와 문서는 MIT 라이선스를 따르며 화면 속 외부 에셋의 권리는 각 제작자에게 있습니다. [사진과 제작진](https://github.com/hjcud/Shimanami-Ekranoplan/blob/main/README.ko.md) / [원본 코드 라이선스](https://github.com/hjcud/Shimanami-Ekranoplan/blob/main/LICENSE)
- **Idea2Strategy**의 로고는 프로젝트 원본이며 전략 목록, 편집기와 백테스트 화면은 예시 데이터로 실행한 UI를 캡처했습니다. 편집 체험은 팀의 React `BasicEditor`를 사용합니다. [로고 원본](https://github.com/Idea2Strategy/Idea2Strategy/blob/c742e486364a8b9d9acaec521eac23f2bb0bd0e1/docs/assets/i2s-logo.svg) / [편집기 소스](https://github.com/Idea2Strategy/Idea2Strategy-ui/blob/ce32bf42747395502c034c2831c02a7220119a10/src/views/StrategyViews.tsx)
- **BetterBatter**의 경기 화면과 데모의 로고, 야구장 배경, 등급 배지는 BetterBatter 팀의 앱에서 가져왔습니다. 데모는 팀이 개발한 중계 및 예측 화면에 예시 경기 데이터를 표시합니다.
- **바로영업**의 전화 수신 이미지에는 프로젝트의 고객 카드와 일정 시연 화면을 담았습니다.

## 기술 배지

- Unity, C#, UdonSharp, Java, Spring, React 배지의 도형은 hjcud의 GitHub 프로필에 사용한 SVG에서 가져왔습니다. [프로필 배지](https://github.com/hjcud/hjcud/tree/main/assets)
- TypeScript, Kotlin, Jetpack Compose, Git 아이콘의 SVG는 Simple Icons에서 가져왔습니다. 컬렉션은 CC0로 배포되며 각 브랜드의 로고에는 해당 권리자의 이용 조건이 적용됩니다. [Simple Icons 라이선스](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md) / [개별 아이콘 출처](https://github.com/simple-icons/simple-icons/blob/develop/data/simple-icons.json)
- Git 로고는 Jason Long의 작품입니다. 배지 색상을 포트폴리오에 맞게 변경했습니다. [Git 로고 원본](https://git-scm.com/community/logos) / [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)
