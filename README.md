# 손현준 프로젝트 포트폴리오

빌드 과정 없이 GitHub Pages에서 제공할 수 있는 HTML, CSS, JavaScript 사이트입니다.

## 화면 구성

상단은 소개와 연락처, 학력과 교육, 기술 경험을 독립된 구간으로 배치했습니다. 학력과 교육은 고등학교부터 SSAFY까지 연결한 가로 타임라인, 기술 경험은 분야별 배지 모음이며 모바일에서는 한 열로 이어집니다. 타임라인이 상단 메뉴 아래에 닿으면 고정되고 스크롤에 따라 자연스럽게 압축됩니다. 기존 연도와 월 눈금, 전체 가로 범위, 카테고리명과 현재 프로젝트 막대의 디자인 및 위치를 유지하며 나머지 행과 안내 영역만 줄입니다. 위로 돌아가면 같은 타임라인이 다시 펼쳐지며 수동 접기 기능은 없습니다.

## 미리보기

Node.js가 설치된 환경에서 이 폴더를 열고 `node serve.mjs`를 실행한 뒤 `http://127.0.0.1:4173`에 접속합니다. 추가 패키지 설치는 필요 없습니다. 서버는 로컬 컴퓨터에서만 접근할 수 있습니다.

## 수정 위치

- `index.html`: 프로젝트 설명, 기간, 역할, 타임라인과 링크
- `styles.css`: 반응형 배치, 색상, 글꼴
- `app.js`: 프로젝트 위치 표시, 미디어 보기, 체험 기능
- `assets/`: 실제 프로젝트 이미지와 영상

체험은 브라우저 안에서 동작하며 서버 API나 로그인, 실시간 시세를 연결하지 않습니다. Idea2Strategy는 원본 React BasicEditor를 정적으로 빌드해 사용합니다. 블록 및 패키지 배치, 값 수정, 되돌리기와 다시 실행을 지원하며 편집 내용은 새로고침하면 초기화됩니다.

## GitHub Pages 배포

공개 주소는 https://hjcud.github.io/ 이며, 저장소는 https://github.com/hjcud/hjcud.github.io 입니다. `main` 브랜치의 루트 폴더를 GitHub Pages 게시 대상으로 사용합니다. 변경 사항을 `main`에 푸시하면 사이트가 갱신됩니다. `index.html`, 모든 CSS와 JS 파일, `.nojekyll`, `assets/`, `strategy-editor/`, `betterbatter-ui/`를 함께 유지해야 합니다. `serve.mjs`는 로컬 미리보기용입니다.

BetterBatter는 저장소의 원본 UI를 고정 테스트 데이터로 실행한 이미지와 별도의 축약 체험을 제공합니다. 바로영업은 2026.10.12부터 진행 중인 SSAFY 프로젝트로, 기능 설계와 Android 개발 내용을 표시합니다.

기술 배지는 상단과 프로젝트에서 같은 모양으로 표시합니다. 상단 배지를 선택하면 해당 기술을 쓴 프로젝트 목록을 볼 수 있고, 프로젝트의 배지를 누르면 상단에서 같은 기술이 선택됩니다. 프로젝트에 표시된 배지에서 관련 목록을 생성하므로 서로 일치합니다.

각 기술 배지에는 동일한 포인트 색상을 사용합니다. AI 항목은 AI 스킬과 하네스 설계로 구분하고, Idea2Strategy에 프로젝트 스킬 활용 및 Stackcord 설계 내용을 표시합니다.

신주쿠 프로젝트는 상단 설명과 실제 스크린샷 슬라이드, 하단 자동 교통 시연으로 구성했습니다. 사진은 5초 간격으로 전환하며 클릭 확대와 좌우 방향키 이동을 지원합니다.

### 신주쿠 교통 시연

- `traffic-data.js`: 전시용 `TechnicalExhibition.unity`의 TrafficLaneDatabase에서 추출한 7개 차선, 810개 좌표 표본, 정지선과 차선 변경 허용 구간.
- `assets/shinjuku-road.svg`: 도로 좌표를 미리 투영한 정적 지도. 역 건물과 보도 주변은 단순화한 일러스트이며 3D 모델의 렌더링 결과가 아닙니다.
- `traffic-core.js`: 차간 거리, 정지선 감속, 전방 보행자 감지, 안전 간격과 허용 구간에 따른 차선 변경, R4 분기를 재현하는 경량 모델.
- `traffic-view.js`: 전시용 계기판의 차량 위치, 예측 영역과 변경 경로 표현을 참고한 Canvas 뷰. 실제 Unity/Udon 런타임 또는 실시간 멀티플레이 동기화를 실행하지 않습니다.

원본 신호 주기 160초, 적색 종료 52.6667초, 황색 시작 155초, 적색 시작 159초를 사용하며 감상을 위해 시뮬레이션 시간을 3배로 진행합니다. 원본은 실제 플레이어를 감지합니다. 웹의 보행자 경로와 교통량은 그 동작을 보여 주는 시연 데이터입니다. 차량 이동은 로컬 모델의 결과이며 실제 월드의 성능 측정값이 아닙니다.

정적 지도는 크기가 변경될 때만 오프스크린 Canvas에 캐시합니다. 화면에 보일 때만 초기화하며 최대 30fps, DPR 1.5로 제한합니다. 화면 밖이나 백그라운드 탭에서는 requestAnimationFrame을 취소합니다. 모션 감소 설정에서는 정지 화면을 제공하고, 작은 일시정지 버튼만 남겼습니다. 모든 경로는 상대 경로이며 외부 라이브러리나 서버 없이 GitHub Pages에서 실행할 수 있습니다.

교통 시연은 제목과 소개 영역 없이 지도부터 보여 줍니다. 주변을 걷는 일반 보행자는 표시하지 않으며 횡단보도 시연 인물만 남겼습니다.

지도 하단은 실시간 계기판 대신 원본 최적화 기록에 근거한 세 가지 문제와 해결 방법을 요약합니다. 평균 CPU 프레임 비교는 조건과 함께 표시하며, 기존 접이식 최적화 설명은 이 영역에 통합했습니다.

최적화 설명은 경로 재사용, 검사 분산, 위치 보간의 SVG 비교 장면으로 표시합니다. 화면 중앙에 가장 가까운 장면 하나만 30fps 이하로 재생하고, 나머지는 정지합니다. 모션 감소 설정과 시연 일시정지 버튼을 따르며, 탭이 숨겨지면 연산을 멈춥니다. 비교 장면의 시간과 작업 블록은 원리 설명용으로 단순화했습니다. CPU 막대는 0을 기준으로 같은 축을 사용합니다.

지도는 도로와 횡단보도를 중심으로 확대하고, 최적화 비교는 별도 카드로 분리했습니다. 물리 검사의 대상 분리(앞차/신호는 차선 정보, 사람/장애물은 물리 검사)를 설명하는 비교를 추가했습니다.

프로젝트는 기본적으로 접혀 있으며 한 번에 하나만 펼쳐집니다. 신주쿠의 CPU 개선 과정과 항공기의 좌표 오차 개선 과정은 프로젝트를 열면 성과 아래에 바로 표시합니다. 내부 펼치기 버튼은 일반 소제목으로 바꿨습니다. 신주쿠 비교 장면은 프로젝트를 연 뒤 초기화하며, 프로젝트를 닫으면 재생 프레임을 취소합니다. 보충 설명의 별도 접기는 유지합니다.

### Shimanami 비행 시연

`flight-model.js`는 타일 번호와 내부 좌표 분리, 타일 경계 보정, 환경의 역변환을 계산합니다. `flight-view.js`는 외부 추적 시점에서 기체의 방향과 피치, 롤을 회전시킵니다. 원본은 기체를 고정하고 환경을 역변환하므로, 시연은 관찰 좌표계를 바꿔 자세 변화를 보여 줍니다. 타일 경계에서는 내부 좌표 표시가 되돌아가고 타일 번호와 기준 영역이 바뀌며 지형의 화면 위치는 연속적으로 유지됩니다. 반복되는 섬 무늬 대신 연속된 해안선을 사용합니다. 방향각, 기수 각도, 좌우 기울기와 현재 타일 좌표를 함께 표시합니다. 지형과 기체는 설명용 도형이며 원본 Unity 장면이나 실제 비행 물리 전체를 이식한 것은 아닙니다.

전시 전 환경 이동 방식과 전시 후 타일 좌표 개선을 구분했습니다. 원격 타일 좌표 변환 예시는 코드 구조를 설명하며 소유권 전환 및 중도 입장에 대한 다중 클라이언트 검증 완료를 뜻하지 않습니다.

정적 도형을 캐시하고 화면 밖 타일을 제외합니다. 최대 30fps, DPR 1.5로 제한하며 화면 밖과 숨겨진 탭에서는 재생을 멈춥니다. 모션 감소 설정에서는 정지 화면을 제공합니다. 외부 라이브러리와 서버 API 없이 GitHub Pages에서 동작합니다.

기체는 flight-aircraft.js에서 닫힌 입체 부품으로 구성합니다. 모델의 작은 화면 영역에서만 픽셀별 깊이를 검사하여 회전 시 면 순서가 바뀌는 문제를 방지합니다. 삼각형은 최초 1회 생성하고 픽셀/깊이 버퍼를 재사용합니다. 고정 X/Z 좌표축과 기체 위치 X 0 / Z 0 표시를 환경의 타일 좌표와 구분했습니다.

지도 왼쪽 아래 계기판에는 방향각, 기수 각도, 좌우 기울기만 표시합니다. 기체 아래 표식은 고정 위치 X 0 / Z 0과 현재 타일 기준 좌표를 함께 보여 줍니다. 타일 경계에서는 이전 기준을 점선, 새 기준을 파란 테두리로 구분하고 전환 화살표를 잠깐 표시합니다.


### Idea2Strategy 원본 편집기

- 이미지: Idea2Strategy/Idea2Strategy 저장소 `docs/assets/features`의 전략 편집, 전략 미리보기, 백테스트 PNG 원본.
- UI: Idea2Strategy/Idea2Strategy-ui의 `BasicEditor` 컴포넌트. 출처와 커밋은 `strategy-editor/SOURCE.txt`에 기록했습니다.
- `strategy-editor/portfolio.html`과 해시가 붙은 CSS/JS는 상대 경로로 연결되어 GitHub Pages의 저장소 하위 경로에서도 동작합니다.
- iframe을 지연 로딩하여 프로젝트 설명만 읽을 때 편집기 로딩을 늦춥니다. 좁은 화면에서는 편집 영역 전체를 같은 비율로 축소합니다.
- 원본 배치, 블록 입력, 패키지, 로컬 검증 및 편집 기록 로직을 사용합니다. API 클라이언트는 null로 전달하고 저장, 봇 출시, 시장 미리보기 메뉴는 감췄습니다. 서버 요청은 편집기 CSP의 connect-src 'none'으로도 차단합니다.
- 추가된 편집기 빌드 용량은 CSS/JS 합계 약 1.02 MB입니다. CDN이나 런타임 서버는 필요하지 않습니다.
- 로컬 재빌드: `work/i2s-ui`에서 `pnpm exec vite build --config vite.portfolio.config.ts`. 원본 이미지는 `work/i2s-source`에 보관합니다.


편집기 표시 수정: 원본 라이트 테마를 적용했습니다. 1280 × 760 편집 화면을 컨테이너 너비에 맞춰 동일 비율로 축소하며, 가로 스크롤을 만들지 않습니다. iframe 내부의 비수동 wheel 처리로 캔버스 확대/축소와 라이브러리 스크롤이 바깥 페이지 스크롤로 전달되지 않도록 했습니다.
